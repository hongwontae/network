1. AWS EC2 생성하기
    1-1. 콘솔창에서 EC2 입력
    1-2. 왼쪽 탭에서 인스턴스 클릭
    1-3. 인스턴스 시작 클릭
    1-4. 이름 : cloud-web-server
    1-5. OS: Ubuntu 24.04 LTS x86_64 선택
    1-6. 인스턴스: t3.micro 선택
    1-7. 키 페어에서 새 키 페어 생성 클릭
        => 이름 : 	cloud-mission-key
        => 키 페어 유형 : 	ED25519
        => 프라이빗 키 파일 형식 : .pem
    1-8. 네트워크 설정
        => vpc : cloud-mission-vpc
        => subnet : cloud-public-subnet
        => 퍼블릭 ip 자동 할당 : 활성화
        => 기존 보안 그룹 선택 : cloud-web-sg
    1-9. 인스턴스 시작


2. ec2:GetSecurityGroupsForVpc 작업을 수행할 권한이 없습니다.
    2-1. cloud-mission-user의 IAM 정책에 EC2 생성 화면에서 
        사용하는 보안 그룹 조회 권한이 빠져 있다는 뜻입니다.
    2-2. 정책 -> cloud-mission-policy 선택 -> 권한 → 편집 클릭
    {
    "Sid": "GetSecurityGroupsForVpc",
    "Effect": "Allow",
    "Action": [
        "ec2:GetSecurityGroupsForVpc"
    ],
    "Resource": "*",
    "Condition": {
        "StringEquals": {
        "aws:RequestedRegion": "ap-northeast-2"
        }
    }
    }   -> 서울 리전의 VPC별 보안 그룹을 조회하는 작업만 추가로 허용합니다.
