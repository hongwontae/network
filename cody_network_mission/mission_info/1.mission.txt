1. 실습 사용자 생성
    1-1. 검색창에서 iam 입력
    1-2. 왼쪽 사이드 바에서 IAM 사용자 클릭
    1-3. 아무런 사용자가 없습니다.
    1-4. 사용자 생성 클릭
        => 사용자 이름 : cloud-lab-console-user
        => 직접 정책 연결
        => 과제에서 AWS가 제공하는 관리자 권한 그대로 부여하지 않아야 함
        => 필요한 권한만 부여해야 함
    1-5. 일단 권한 없이 사용자 생성
        => 권한이 없다면 EC2, VPC, S3 접근 모두 거부됩니다.
        => 우리가 만드는 CloudLabPolicy에 EC2와 VPC 관리에 필요한 작업만 허용할 것입니다.
