1. AWS에서 VPC 생성
    1-1. VPC만
        => AWS는 VPC를 생성할 떄 서브넷, 라우팅 테이블, NAT Gateway을 함께 만들어주는 옵션이 존재합니다.
        => 과제 공부를 위해 VPC만 만들고, 불필요한 NAT Gateway 과금도 피합니다.
    1-2. vpc 이름 : cloud-mission-vpc
    1-3. IPv4 CIDR 블록
        => IPv4 CIDR 수동 입력
    1-4. IPv4 CIDR
        => 10.0.0.0/16
        => 앞의 16 부분은 네트워크 부분으로 사용
    1-5. IPv6 CIDR 블록
        => IPv6 CIDR 블록 없음
    1-6. 테넌시
        => 기본값
    

2. 해석
    2-1. VPC: 10.0.0.0/16
    2-2. 시작 주소는 10.0.0.0
    2-3. 마지막 주소는 10.0.255.255
    2-4. 전체 IPv4 주소는 65,536개
    2-5. /16 -> 앞의 16 bit는 네트워크 부분이라 고정, 뒤의 16 bit는 자유롭게 변경가능


3. AWS IP 주소 특징
    => 65,536개가 모두 EC2에 할당 가능한 주소라는 뜻은 아닙니다.
    => AWS에서는 Subnet마다 처음 4개와 마지막 1개, 총 5개의 IP 주소를 예약합니다.
