1. IAM
    1-1. AdministratorAccess 없이 EC2, VPC, Security Group 
        관리에 필요한 최소한의 권한만 가진 IAM 사용자 또는 역할을 사용해야 합니다.


2. AWS IAM 사용자 생성
    2-1. 왼쪽 메뉴에서 IAM 사용자 클릭
    2-2. 오른쪽 위 사용자 생성 클릭
    2-3. 사용자 이름 : cloud-mission-user
    2-4. AWS Management Console에 대한 사용자 액세스 권한 제공 항목을 선택
        => 자동 생성된 암호 선택
        => 사용자는 다음 로그인 시 새 암호를 생성해야 합니다. -> 권장
    2-5. 권한 옵션에서 그룹에 사용자 추가 선택
    2-6. 그룹 시작하기에서 그룹 생성 클릭
    2-7. 그룹 이름 : cloud-mission-group
    2-8. 사용자 그룹 생성 클릭
        => 나중에 권한을 설정할 예정입니다.
    2-9. 사용자 그룹 탭에서 cloud-mission-group 선택
    2-10. 사용자 생성
