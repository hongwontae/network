1. AWS
    1-1. 직접 서버 컴퓨터를 구입하고 운영하는 대신, 
        아마존이 보유한 컴퓨팅 자원과 서비스를 빌려 쓰는 것이 AWS의 기본적인 개념입니다.
    1-2. AWS가 제공하는 서비스와 그 서비스를 사용하는 사용자는 다른 존재입니다.


2. AWS 계정
    2-1. AWS 서비스를 사용하려면 AWS 계정이 필요합니다.
    2-2. AWS 리소스의 소유권, 권한 관리, 사용량 및 비용을 구분하는 기본 단위입니다.
    2-3. 관리 계정 -> AWS 계정이 AWS Organizations 전체를 관리하는 특별한 계정


3. IAM 계정
    3-1. AWS 계정을 하나 만들었다고 가정, 그 계정을 관리할 사람이 여러 명
    3-2. 모든 사람에게 루트 계정 비밀번호를 공유하는 것은 위험
    3-3. IAM(Identity and Access Management)은 누가 AWS에 접근할 수 있고,
         어떤 작업을 수행할 수 있는지 관리하는 서비스입니다.
    3-4. AWS 계정 A가 존재하고, 그 안에 Root user, IAM 사용자가 존재합니다.


4. 정리
    4-1. AWS 계정 A: AWS 리소스를 소유하는 단위
    4-2. Root user: 계정에 대한 최고 권한을 가진 특별한 로그인 신원
    4-3. IAM 사용자 hong: 계정 A에 소속되어 부여받은 권한으로 작업하는 신원
        => 계정 당 root 계정 하나와 여러 IAM 계정이 존재합니다.
