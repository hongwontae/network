    1-5. VPC : cloud-mission-vpc 선택


2. 인바운드 규칙
    2-1. 규칙 추가 클릭
    2-2. http, 포트 80, 소스에서 Anywhere-IPv4 선택, 0.0.0.0/0 확인
        => 이 규칙은 인터넷의 모든 IPv4 주소에서 웹 서버의 80번 포트로 접근하는 것을 허용합니다.
    2-3. 규칙 추가 클릭
    2-4. SSH, 포트 22, 소스에서 내 IP, .../32 
        => 인터넷 연결에 사용되는 공인 IPv4 주소를 /32로 지정할 수 있습니다.
        => /32는 정확히 하나의 IPv4 주소를 의미합니다.
        => 인터넷의 모든 사용자가 SSH에 접근하는 것을 방지할 수 있습니다.
