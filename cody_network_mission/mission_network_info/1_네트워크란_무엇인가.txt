1. 네트워크
    1-1. 여러 장치가 서로 데이터를 주고받을 수 있도록 연결된 구조입니다.
    1-2. 간단히 말하자면 컴퓨터나 다른 장치들이 서로 통신할 수 있도록 연결된 시스템
        => 반드시 케이블이 필요한건 아니며, WIFI처럼 전파를 사용하는 무선 네트워크도 존재합니다.


2. 스위치
    2-1. 연결된 장치들 사이에서 데이터를 적절한 목적지로 전달하는 장치입니다.
    2-2. 컴퓨터 n개와 스위치가 하나가 네트워크를 구성했다고 볼 수 있습니다.
        => 네트워크는 인터넷에 연결되어 있지 않아도 네트워크라고 합니다.


3. 공유기
    3-1. 여러 기능을 하나의 기기에 넣은 제품입니다.
    3-2. 라우터(Router): 서로 다른 네트워크 사이에 IP 패킷을 전달합니다.
    3-3. 스위치(Switch): 유선 장치 여러 대를 연결합니다.
    3-4. 무선 AP(Access Point): 스마트폰이나 노트북이 Wi-Fi로 연결되도록 합니다.
    3-5. NAT 기능: 집 안의 여러 장치가 하나의 공인 IPv4 주소를 공유해서 인터넷에 접속할 수 있도록 합니다.


4. LAN
    4-1. 집이나 사무실 같은 제한된 공간에서 연결된 네트워크를 LAN이라고 합니다.

5. WAN
    5-1. 멀리 떨어진 네트워크들을 연결하는 광역 네트워크가 WAN이라고 합니다.
    5-2. 서울의 사무실 LAN과 부산의 사무실 LAN을 통신사업자의 회선으로 연결한다면,
             그 사이의 광역 연결이 WAN을 구성할 수 있습니다.


6. 인터넷
    6-1. 인터넷은 전 세계의 수많은 네트워크가 서로 연결되어, 
            공통된 통신 규칙을 통해 데이터를 주고받을 수 있는 거대한 네트워크 시스템입니다.
    6-2. 서로 다른 회사가 만들고 관리하는 네트워크들이 어떻게 통신할 수 있을까?
        => 공통된 통신 규칙인 인터넷 프로토콜 모음(TCP/IP)을 사용합니다.
    6-3. IP는 목적지까지 패킷을 전달하는 데 필요한 주소 체계를 제공
    6-4. TCP는 많은 응용 프로그램에서 데이터가 순서대로 안정적으로 전달되도록 도와줍니다.

    6-5. 인터넷도 결국 실제 하드웨어로 구성되어 있습니다.
        1. 광섬유 케이블
            => 빛을 이용해 데이터를 전송하는 케이블입니다.
            => 도시와 도시, 국가와 국가 사이에서 대량의 데이터를 빠르게 전송하는 핵심 인프라입니다.

        2. 라우터(Router)
            => 목적지 IP 주소를 참고해 패킷을 다음 네트워크로 전달하는 장치

        3. 서버(Server)
            => 웹사이트, 게임, 파일 등 다양한 서비스를 제공하는 컴퓨터
        
        4. 해저 통신 케이블
            => 바다 아래에 설치된 광섬유 케이블
            => 대륙과 대륙 사이의 인터넷 트래픽 상당 부분이 이 케이블을 통해 전달됩니다.


7. 집 컴퓨터와 인터넷 연결 과정
    7-1. 내 컴퓨터 -> 공유기
        => 공유기를 통해 외부 네트워크로 데이터를 보낼 수 있습니다.
    7-2. 공유기 -> ISP
        => 공유기는 외부로 향하는 데이터를 ISP 통신망 쪽으로 전달합니다.
    7-3. ISP -> 다른 네트워크들
        => ISP는 목적지에 따라 자신의 라우터나 다른 통신사업자와의 연결을 통해 데이터를 전달
    7-4. 목적지 서버
        => 여러 네트워크를 거쳐 최종적으로 요청이 목적지 서버에 도착
