1. IP (Internet Protocol) (IP, IP 주소는 다른 개념)
    1-1. IP는 서로 다른 네트워크에 있는 장치들이 데이터를 주고받을 수 있도록 정해 놓은 통신 규칙입니다.
    1-2. IP 기능
        => 주소 지정(Addressing): 출발지와 목적지의 IP 주소를 사용해 통신 대상을 구분
        => 패킷화(Packetizing): 전송할 데이터를 IP 헤더가 포함된 패킷 형태로 구성
        => 라우팅(Routing): 라우터들이 목적지 IP 주소를 바탕으로 패킷을 전달할 경로를 결정할 수 있게 함


2. IP 주소
    2-1. IP 주소는네트워크에서 장치의 네트워크 인터페이스를 식별하고, 패킷을 목적지까지 전달하는 데 사용하는 논리적인 주소
    2-2. 네트워크 인터페이스
        => 컴퓨터가 연결되려면 외부와 데이터를 주고 받을 수 있는 장치가 필요합니다.
        => 대표적인 두 가지 방법 : 유선 연결(유선 랜카드), 무선 연결(wifi 어댑터)
        => 컴퓨터에는 네트워크 통신을 담당하는 별도의 하드웨어 존재
        => 네트워크 인터페이스란 컴퓨터가 네트워크와 데이터를 주고받는 접점입니다.
        => 데이터를 주고 받을 통로가 필요하고 그 통로가 네트워크 인터페이스고 랜카드와 wifi 어댑터는 그 통로를
            실제로 구현하는 네트워크 인터페이스입니다.
    2-3. 논리적인 주소
        => 하드웨어에 영구적으로 새겨진 번호가 아니라, 네트워크 구성에 따라 할당하고 변경할 수 있는 주소
    
    2-4. IP 주소는 컴퓨터 자체에 영구적으로 하나씩 부여되는 정보가 아닙니다.
        => IP 주소는 보통 네트워크 인터페이스에 할당됩니다.
        => 노트북에 유선 이더넷 인퍼테이스, 무선 wifi 인터페이스 -> 각기 다른 IP 주소
        => 즉, 하나의 컴퓨터가 여러 IP 주소 가질 수 있습니다.
        => 그리고 하나의 네트워크 인터페이스에도 여러 IP 주소 할당 가능, 네트워크 환경 바뀌면 IP 주소 달라질 수 있습니다.

    2-5. IP4 vs IP6
        구분	    IPv4	    IPv6
        주소 크기	32비트	      128비트
        주소 예시	192.168.0.1	 2001:db8::1
        주소 개수	약 43억 개	  약 3.4 × 10³⁸개
    
    2-6. IP4
        => 32 bit 크기의 주소 체계 사용합니다.
        => 표현할 떄는 네 개의 숫자로 나눠서 표현합니다.
        => 11000000 10101000 00000000 00000001 -> 192.168.0.1
        => 8비트씩 네 부분으로 나누고, 각각을 10진수로 바꿔서 .으로 구분합니다. -> 이를 10진 표기법이라고 합니다.
        => 각 부분은 8비트, 표현할 수 있는 값이 0 ~ 255입니다. -> 0~255 . 0~255 . 0~255 . 0~255
        => 이 범위의 모든 조합을 자유롭게 사용 x -> 약된 주소와 특수한 용도가 존재
    
    2-7. 사설 IP와 공인 IP

        1. 사설 IP
            => 집, 회사, AWS VPC 같은 사설 네트워크 내부에서 사용하는 주소입니다.
            => IP4에서 사설 IP로 예약된 범위
            주소 범위	                        CIDR 표기
            10.0.0.0 ~ 10.255.255.255	    10.0.0.0/8
            172.16.0.0 ~ 172.31.255.255	    172.16.0.0/12
            192.168.0.0 ~ 192.168.255.255	192.168.0.0/16
            
            => 집 컴퓨터와 다른 사람의 집 컴퓨터가 모두 192.168.0.2라는 IP 주소를 사용할 수 있습니다.
            => 서로 다른 사설 네트워크에서 독립적으로 사용하는 주소
            => 사설 IP 주소는 일반적인 공용 인터넷에서 직접 라우팅되지 않습니다.
            => 
        
        2. 공인 IP
            => 전 세계 인터넷에서 라우팅될 수 있도록 할당·관리되는 주소입니다.
            => 공인 IP는 인터넷 전체에서 주소가 충돌하지 않도록 관리합니다.
            => 방화벽, 라우팅, 보안 그룹 등의 설정에 따라 외부 접근이 차단될 수 있습니다.

    2-8. 컴퓨터에서 인터넷 접속 과정
        => 집의 컴퓨터에는 사설 IP인 192.168.0.2가 할당되어 있다고 가정
        => 사설 IP는 공용 인터넷에서 직접 라우팅되지 않습니다.
        => NAT(Network Address Translation)**라는 기술을 이용합니다. (IPv4 공유기에서는 보통 NAPT라는 방식)
        => 외부에 패킷을 보낼 떄 공유기는 NAT을 사용해서 사설 IP를 공인 IP로 변환하고 변환정보를 기억합니다.
        => 이러한 과정 떄문에 여러 장치가 하나의 공인 IP 주소를 공유해서 인터넷에 접속할 수 있습니다.
    
    2-9. IP 주소 할당
        
        1. 정적 할당
            => 관리자가 네트워크 설정에 주소를 직접 지정하는 방식
        
        2. 동적 할당
            => DHCP(Dynamic Host Configuration Protocol) 같은 프로토콜을 통해 자동으로 할당받는 방식
        
        3. IP 주소 할당 흐름
            => 스마트폰이 네트워크에 연결됩니다.
            => DHCP 서버(가정에서는 보통 공유기)가 사용할 IP 주소를 제안합니다.
            => 스마트폰이 해당 주소를 할당받습니다.
            => 서브넷 마스크, 기본 게이트웨이, DNS 서버 같은 설정도 함께 전달받을 수 있습니다.
