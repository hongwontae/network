1. 서로 다른 네트워크에 속하는 컴퓨터가 존재할 떄 데이터를 보내기 위해서는 라우터가 필요합니다.


2. 라우터
    2-1. 서로 다른 IP 네트워크 사이에서 패킷을 전달하는 장치입니다.
        => 패킷은 네트워크를 통해 전달하기 위해 구성한 데이터 단위
    
    2-2. 컴퓨터 A와 컴퓨터 B가 라우터에 연결되어 있습니다.
        => 192.168.1.1: 네트워크 A와 연결된 인터페이스
        => 192.168.2.1: 네트워크 B와 연결된 인터페이스
        => 컴퓨터 A가 B에게 데이터를 보내면 라우터가 이를 받아 네트워크 B로 전달할 수 있습니다.
        => 이처럼 라우터는 네트워크와 네트워크를 연결하는 역할


3. 라우팅
    => 데이터를 목적지 네트워크까지 전달하기 위해 경로를 선택하는 과정입니다.
    => 목적지 IP 주소와 라우팅 테이블 바탕으로 전달 경로를 선택하는 것입니다.
