1. VPC
    1-1. 집 컴퓨터는 공유기에 연결, 회사 컴퓨터는 회사 네트워크에 연결됩니다.
        => AWS의 EC2 인스턴스도 네트워크가 필요합니다.
        => 네트워크 환경을 구성하는 핵심 서비스가 VPC(Virtual Private Cloud)입니다.
    
    1-2. VPC란 WS 클라우드 안에 생성하는 논리적으로 격리된 가상 네트워크입니다.
        => AWS 안에 내가 사용할 네트워크 공간을 구성하는 것입니다.
    
    1-3. 예시
        => VPC 이름: My-VPC
        => IPv4 CIDR: 10.0.0.0/16
        => 네트워크 부분 16, 호스트 부분 16, 전체 IPv4 주소 65,536개
        => 네트워크 시작 부분은 0000 1010 0000 0000
        => 호스트 부분은 0000 0000 0000 0000 
        => EC2 같은 자원을 연결할 서브넷을 이 범위 안에 만들어야합니다.
            -> 10.0.0.0 ~ 10.0.255.255


2. Subnet
    2-1. VPC의 IP 주소 범위를 더 작은 범위로 분할한 네트워크입니다.
    2-2. 고정된 네트워크 값이 아닌 호스트 부분을 변경한 것입니다.
        => 10.0.0.0/16
